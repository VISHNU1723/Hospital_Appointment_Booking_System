# Hospital Appointment Booking System

## Project Overview
A hospital appointment booking backend built using FastAPI, Python, MySQL, SQLAlchemy, and Alembic. The system supports appointment management, consultations, email notifications, real-time queue updates, reports, prescription PDF downloads, and patient reviews.

## Features
- User authentication and role-based access control
- Department, doctor, and patient management
- Doctor schedules and leave management
- Appointment booking, check-in, rescheduling, and cancellation
- Consultation records and prescription PDF downloads
- Appointment file uploads and downloads
- SMTP email notifications and scheduled reminders
- WebSocket-based real-time queue updates
- Admin reports and dashboard
- Patient ratings and feedback for doctors

## Technology Stack
- Python
- FastAPI
- SQLAlchemy
- MySQL
- Pydantic
- Alembic
- Uvicorn
- APScheduler
- SMTP
- WebSockets

## Setup Instructions

### 1. Prerequisites
Install Python, MySQL, and Git.

### 2. Clone the repository
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd HOSPITAL_APPOINTMENT_SYSTEM
```

### 3. Create and activate a virtual environment
macOS/Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 4. Install dependencies
```bash
pip install -r requirements.txt
```

### 5. Configure environment variables
Create a local `.env` file and configure the variables required by the application.

Example:
```dotenv
DATABASE_URL=mysql+pymysql://DB_USER:DB_PASSWORD@localhost:3306/YOUR_DATABASE
SECRET_KEY=replace_with_a_secure_random_secret
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=60

SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USERNAME=your_email@gmail.com
SMTP_PASSWORD=your_google_app_password
SMTP_FROM=your_email@gmail.com
```

Check `app/database.py`, the authentication code, and `app/services/email_service.py` for the exact variable names expected by the project. Use your own database credentials and SMTP settings.

**Security:** Never commit `.env`, passwords, access tokens, or secret keys to GitHub.

### 6. Run database migrations
Check the current migration:
```bash
alembic current
```

View migration history:
```bash
alembic history
```

Generate a migration after a model change:
```bash
alembic revision --autogenerate -m "describe the change"
```

Apply migrations:
```bash
alembic upgrade head
```

Review autogenerated migrations before applying them, especially operations that drop tables, indexes, columns, or foreign keys.

### 7. Start the application
```bash
uvicorn app.main:app --reload
```

Open Swagger UI:
http://127.0.0.1:8000/docs

## SMTP Email Setup
1. Configure the SMTP variables in `.env`.
2. For Gmail, configure an App Password if required by your account.
3. Restart the application.
4. Trigger an appointment booking, cancellation, or reminder.
5. Verify the email in the recipient inbox and spam folder.

Scheduled emails require the scheduler to start correctly with the application.
